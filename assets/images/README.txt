Tips:
- Pakai format .jpg atau .webp, lebar 1200px sudah cukup, ukuran file usahakan di bawah 300 KB.
- Mau pakai nama atau format lain (misal .png)? Ubah juga path-nya di index.html
  dan js/projects.js.
